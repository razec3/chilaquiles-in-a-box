1. One or more valid mock dish proposals are displayed.
2. A dish can be selected and its scaled ingredients viewed.
3. The selected dish can be confirmed.
4. An order draft with product pack quantities and displayed prices is shown.
5. The order draft can be downloaded as JSON.
